TylerCast: Windows test round 1

About 10 minutes on the Windows laptop, with the TV nearby. One script does everything and sends the results back to the Mac.

  1. Open PowerShell on the Windows laptop

    Press the Windows key, type PowerShell, and open Windows PowerShell. Don't use "Run as administrator": it doesn't need it.

  2. Paste this line and press Enter

    irm __BASE__/round.ps1 | iex

    It downloads TylerCast (about 50 MB) into a folder on your Desktop, TylerCast-round1. Nothing is installed and no settings are changed.

  3. Follow the prompts in the PowerShell window

    • Self-test (1–2 minutes): leave the mouse and keyboard alone. A pink box flashes at the top-left of the screen, and you'll hear two short beeps.
    • TV checks (about 3 minutes): turn the TV on (normal TV or HDMI input, not standby). You'll be asked a few yes/no questions about what the TV shows.
    • If Windows asks to allow TylerCast on the network, tick Private networks and click Allow.
    • For the screen check, start something with sound first (a YouTube video, music).

  4. That's it

    At the end the script sends the results to the Mac by itself and says "All done".

If something goes wrong

The PowerShell line fails or nothing downloads: check the laptop is on the same Wi-Fi as the Mac, then reload this page.

Download TylerCast by hand: tylercast.exe (about 50 MB).
